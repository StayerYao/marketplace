# Stayer Marketplace

Stayer 的 Claude Code 技能和插件集合。

## 安装

添加此 marketplace 到 Claude Code：

```bash
/plugin marketplace add StayerYao/marketplace
```

## 可用插件

### pm-solution-design

**描述：** 结构化 PRD 输出 — 四道门禁驱动需求从模糊到可执行

**安装：**
```bash
/plugin install pm-solution-design@stayer-marketplace
```

**你将获得：**
- `pm-solution-design` skill — PM 门禁 PRD 输出流程
- PRD 模板和示例
- 评估场景参考

**仓库：** https://github.com/StayerYao/PM-Solution-Design-Skills

**当前版本：** v1.3.5 — 系统性设计与业务对象边界优化
