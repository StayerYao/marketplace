# Stayer Marketplace

Stayer 的 Claude Code 技能和插件集合。

## 安装

添加此 marketplace 到 Claude Code：

```bash
/plugin marketplace add StayerYao/marketplace
```

## 可用插件

### pm-solution-design

**描述：** PM Solution Design 2.0 — 以 flow 状态机和 G1-G4 门禁驱动 PRD、方案 Brief 与快速草稿输出

**安装：**
```bash
/plugin install pm-solution-design@stayer-marketplace
```

**你将获得：**
- `pm-solution-design` skill — 启动器与守门员
- `references/flow.md` — S0-S8 状态机和 G1-G4 门禁
- PRD / Brief 内容契约、五态覆盖、执行基线和 v2 eval

**仓库：** https://github.com/StayerYao/PM-Solution-Design-Skills

**当前版本：** v2.0.0 — flow 状态机重写、输出范围交互、PRD/Brief 契约和 v2 eval
